Perplexity MCP Bridge

Secure bridge from Home Assistant to Perplexity (MCP over Cloudflare)

Welcome

This add-on exposes only the Home Assistant entities you choose as MCP tools. Remote access uses Cloudflare Tunnel — no router port forwarding.

  • Default: nothing is exposed until you save a selection (or choose “all supported”).
  • Sensors are read-only; actions are limited to safe, domain-specific tools.
  • Use a dedicated subdomain for MCP, not your main Home Assistant URL.

Entities

Load entities from Home Assistant and choose what may appear in MCP.

Connecting to Home Assistant

Normally the Supervisor injects API access automatically. If status shows “Not connected”, create a Long-Lived Access Token in Home Assistant (Profile → Security) and paste it below. That token only talks to Home Assistant — it is not the same as the MCP bearer token (step 4), which protects the public MCP endpoint for Perplexity.

Filter

Click “Fetch entities” to load the list.

Cloudflare Tunnel

Paste your tunnel token and the dedicated hostname for this MCP service.

MCP authentication (Perplexity)

Clients calling your public MCP URL must send this secret. It is not your Home Assistant login or Long-Lived Token.

Bearer token

A random secret generated for this add-on. Perplexity (or any MCP client) sends Authorization: Bearer <this-token>. Rotate it anytime from here.

Review & launch

Save settings, then start the tunnel when ready.

Public MCP URL

Use Authorization: Bearer <MCP token> in the client.
