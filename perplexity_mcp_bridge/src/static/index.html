Perplexity MCP Bridge

Säker brygga mellan Home Assistant och Perplexity (MCP)

Välkommen

Denna add-on publicerar endast de Home Assistant-entiteter du väljer som verktyg via ett MCP-gränssnitt. Åtkomst från internet sker via Cloudflare Tunnel — inga routerportar behöver öppnas.

  • Standard: inget exponeras förrän du sparar ett aktivt urval (eller väljer ”alla stödda”).
  • Sensorer är skrivskyddade; styrning sker bara via tillåtna verktyg per domän.
  • Använd en dedikerad underdomän för MCP, inte samma som din HA-inloggning.

Entiteter

Hämta listan från Home Assistant och välj vad som får synas i MCP.

Filtrera

Klicka på ”Hämta entiteter” för att ladda listan.

Cloudflare Tunnel

Klistra in tunnel-token från Cloudflare och ange den dedikerade värdnamnet för MCP.

Autentisering

MCP-anrop kräver en bärartoken. Lämna tom för att behålla befintlig token.

Granska och starta

Spara inställningarna och starta tunneln när du är redo.
